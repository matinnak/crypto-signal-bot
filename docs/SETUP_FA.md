# راهنمای راه‌اندازی (فارسی)

این ربات روی **GitHub Actions** اجرا می‌شود: هر ساعت یک بار، رایگان و بدون نیاز به سرور.

## ۱. ساخت ربات تلگرام

1. در تلگرام به `@BotFather` پیام بدهید و `/newbot` را بفرستید.
2. اسم و یوزرنیم (که به `bot` ختم شود) بدهید.
3. **توکن** را که می‌دهد نگه دارید و به هیچ‌کس ندهید.

## ۲. پیدا کردن Chat ID خودتان

1. ربات خودتان را باز کنید و `/start` را بزنید.
2. در مرورگر باز کنید (به‌جای `TOKEN` توکن خودتان):
   `https://api.telegram.org/botTOKEN/getUpdates`
3. عدد جلوی `"chat":{"id":` همان **Chat ID** شماست.

## ۳. یک رمز برای رمزنگاری اطلاعات ربات

یک رمز طولانی و تصادفی بسازید (مثلاً ۳۰ کاراکتر). اطلاعات ربات (کاربران، استراتژی‌ها، ارزها) با این رمز رمزنگاری می‌شود و روی شاخه‌ی `state` ریپو ذخیره می‌شود. **اگر این رمز را گم کنید یا عوض کنید، اطلاعات قبلی ربات از دست می‌رود.**

## ۴. وارد کردن Secretها در GitHub

در صفحه‌ی ریپو: **Settings ← Secrets and variables ← Actions ← New repository secret**

| Name | مقدار |
|---|---|
| `TELEGRAM_TOKEN` | توکن BotFather |
| `ADMIN_CHAT_ID` | Chat ID شما (فقط عدد) |
| `STATE_KEY` | رمزی که در مرحله‌ی ۳ ساختید |

اختیاری، در همان صفحه تب **Variables**:

| Name | توضیح |
|---|---|
| `TIMEZONE` | پیش‌فرض `Asia/Tehran` |
| `OPEN_ACCESS` | اگر `true` باشد، همه بدون تأیید ادمین می‌توانند از ربات استفاده کنند |

## ۵. اولین اجرا

1. به ربات خودتان در تلگرام `/start` بفرستید.
2. در GitHub به تب **Actions** بروید. اگر پیام فعال‌سازی نشان داد، فعالش کنید.
3. از سمت چپ **Signal bot (hourly)** را انتخاب کنید و **Run workflow** را بزنید.
4. حدود یک دقیقه بعد، ربات جواب `/start` را می‌دهد. 🎉

از این به بعد ربات **هر ساعت** خودش اجرا می‌شود.

## ۶. استفاده

```
/strategies                       لیست استراتژی‌ها (۴ نمونه‌ی آماده دارد)
/test ema_cross BTCUSDT 4h        سیگنال‌های اخیر روی گذشته، برای مقایسه با TradingView
/add BTCUSDT 4h ema_cross         شروع دریافت سیگنال
/add BTCUSDT,ETHUSDT 1h,4h 2      چند ارز و تایم‌فریم با هم (2 = شماره‌ی استراتژی)
/list   /remove 1                 مدیریت لیست
```

ساخت استراتژی جدید (فقط ادمین):

```
/new rsi_ema
buy: RSI(14) < 30 and close > EMA(200)
sell: RSI(14) > 70
desc: خرید در اشباع فروش، فقط در روند صعودی
```

برای دیدن همه‌ی اندیکاتورها و نحوه‌ی نوشتن شرط: `/indicators`

## نکته‌های مهم

- **جواب دستورها تا یک ساعت طول می‌کشد**، چون ربات ساعتی اجرا می‌شود. برای جواب فوری، در تب Actions دکمه‌ی **Run workflow** را بزنید.
- **تایم‌فریم‌های کمتر از ۱ ساعت** (مثل 15m) هم کار می‌کنند، ولی سیگنال‌هایشان هر ساعت یک‌جا و با تأخیر می‌رسد.
- اجرای ساعتی GitHub گاهی چند دقیقه تا ربع ساعت دیرتر شروع می‌شود.
- اگر ریپو عمومی باشد و ۶۰ روز در آن تغییری داده نشود، GitHub اجرای زمان‌بندی‌شده را غیرفعال می‌کند. در آن صورت از تب Actions دوباره فعالش کنید.
- اگر مشکلی پیش آمد، در تب Actions روی آخرین اجرا کلیک کنید و لاگ مرحله‌ی **Run bot** را ببینید.
- داده‌ها از بازار **اسپات** Binance گرفته می‌شود.
- این ابزار فقط اطلاع‌رسانی است و توصیه‌ی مالی نیست.
